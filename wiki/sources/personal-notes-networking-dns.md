# Source: DNS

> Cập nhật lần cuối: 2026-08-03

## Tóm tắt

Ghi chú mô tả DNS như phone book chuyển domain name thành IP address. Lookup đi qua resolver, root server, TLD server và authoritative server; resolver có thể cache kết quả.

Note cũng liệt kê các record phổ biến: `A`, `AAAA`, `CNAME`, `MX`, `TXT`, `NS`.
