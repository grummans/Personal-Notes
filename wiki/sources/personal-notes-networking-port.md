# Source: Port

> Cập nhật lần cuối: 2026-08-03

## Tóm tắt

Ghi chú giải thích port là cơ chế phân biệt traffic giữa nhiều service trên cùng một server/IP address.

Port nằm ở OSI Layer 4 Transport. IP đưa packet tới đúng máy, còn TCP/UDP dùng port trong header để chuyển dữ liệu tới đúng service. Note cũng liệt kê dải well-known, registered và ephemeral ports cùng một số port mặc định như SSH `22`, DNS `53`, HTTP `80`, HTTPS `443`.
