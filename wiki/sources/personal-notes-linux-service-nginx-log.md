# Source: Nginx Log

> Cập nhật lần cuối: 2026-07-29

## Tóm tắt

Ghi chú đặt log Nginx tại `/var/log/nginx/`. `access.log` lưu request; `error.log` lưu lỗi như `502 Bad Gateway`, permission denied, SSL error hoặc config error.
