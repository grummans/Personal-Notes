# Source: Subnetting

> Cập nhật lần cuối: 2026-08-03

## Tóm tắt

Ghi chú mô tả IPv4/IPv6, cách IPv4 chia thành Network ID và Host ID, các dải private network, subnetting và CIDR notation.

Subnetting được hiểu là chia một network lớn thành các subnet nhỏ hơn bằng cách mượn bit từ phần host. CIDR notation dạng `IP/prefix` cho biết kích thước network; ví dụ `/24` có `2^(32-24) = 256` địa chỉ.
