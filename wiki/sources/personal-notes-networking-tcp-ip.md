# Source: TCP/IP

> Cập nhật lần cuối: 2026-08-03

## Tóm tắt

Ghi chú mô tả TCP/IP là protocol model Internet dùng trong thực tế. TCP/IP gom layer 5, 6, 7 của OSI thành Application layer và gom layer 1, 2 thành Network Access (Link) layer.

Mô hình gồm 4 layer: Application với HTTP/HTTPS/FTP/DNS/SMTP/SSH; Transport với TCP/UDP; Internet với IP, IPv4/IPv6, ICMP, ARP; Network Access với Ethernet, Wi-Fi, MAC và physical drivers. Note cũng nêu vai trò của từng layer: Network Access di chuyển dữ liệu trong cùng physical network, Internet route/forward packet giữa các network, Transport chia/reassemble dữ liệu, Application là nơi chương trình như browser/mail client hoạt động.
