# Source: VMS system flow

> Cập nhật lần cuối: 2026-08-06

## Tóm tắt

Ghi chú mô tả pipeline VMS: camera tạo original RTSP stream, VMS Staging thu thập stream, RTSP Server restream/clone thành nhiều luồng, VMS Server nhận các luồng để quản lý camera/user/permission, rồi VMS Client hiển thị lên monitor.
