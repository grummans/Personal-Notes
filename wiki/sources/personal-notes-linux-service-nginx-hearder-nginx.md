# Source: Nginx Headers

> Cập nhật lần cuối: 2026-07-29

## Tóm tắt

Ghi chú giải thích các reverse proxy header phổ biến: `Host`, `X-Real-IP`, `X-Forwarded-For` và `X-Forwarded-Proto`. Các header này giúp backend như Tomcat biết client IP, host gốc và protocol gốc.
