# Source: Routing

> Cập nhật lần cuối: 2026-08-03

## Tóm tắt

Ghi chú mô tả routing là quá trình chuyển packet từ source tới destination và chọn best path qua một hoặc nhiều network.

Routing dùng routing table và routing protocol để quyết định. Routing table chứa destination range, gateway/netmask/interface; cách đọc rule là `Destination via Next Hop dev Interface`.
