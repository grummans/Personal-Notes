### 802.3ad LACP Mode

- Use for case `HA + Bandwidth`

```
Server

eth0

eth1

↓

Switch

LACP Group
```

-> Switch + Server will ask `LACP` to create a single logical link.

E.g: 1Gbps + 1Gbps = 2Gbps logical

> a single TCP connection go through a single physical point, so a client doest not always achieve 2Gbps.
>
> Total network bandwidth increses when many flows are distributed on different way.
