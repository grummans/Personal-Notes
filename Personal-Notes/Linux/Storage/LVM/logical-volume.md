### Logical Volume

E.g:

```
vg_data
1000Gb
```

->

```
lv_database 400Gb
lv_logs     200Gb
lv_app      100Gb
```

Diagram:

```
VG: vg_data 1000GB

┌────────────────────────────────────────────┐
│                                            │
│  lv_database    400GB                      │
│                                            │
├────────────────────────────────────────────┤
│  lv_logs        200GB                      │
├────────────────────────────────────────────┤
│  lv_app         100GB                      │
├────────────────────────────────────────────┤
│  FREE           300GB                      │
└────────────────────────────────────────────┘
```
